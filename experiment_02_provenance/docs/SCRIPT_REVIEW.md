# 原始脚本检查：需要修正或讨论的事项

此清单来自静态阅读，不是实际运行或论文结论。`src/teacher/` 原件保持不变。工程修复可放在 `src/` 的新模块；涉及研究规则时先与负责人讨论，并记变更。

| 优先级 | 发现 | 影响与建议 |
| --- | --- | --- |
| 正式采集前 | run_experiment 五次调用失败后返回空字符串，仍写成已完成记录；续跑只看 ID | 无法靠重跑同一命令补齐失败。引入显式状态，技术失败可续跑，内容/解析问题单列，不盲目重生成 |
| 预实验分析前 | pilot 六标签缺少 L04 等比较项，analyze 仍计算全部 C1–C5 | 某些比较空缺，p 为 NaN，Holm 可能受影响；只分析支持的比较，缺失项说明，不擅自改变基线 |
| 正式采集前 | 只保存请求中的模型名、评分和文本响应 | 缺实际版本、时间、usage、request ID、finish_reason、参数；补齐平台原始响应和 run log |
| 正式采集前 | 文件写入无逐条显式 flush；无显式超时和预算监控 | 需改为逐调用持久化，并记录每次 attempt；确保中断与预算暂停可恢复 |
| 分析前 | mixed 只检验 bse 有限，没有检验 res.converged，且吞掉 warning | 不能保证已收敛；输出拟合/收敛/回退信息，建立可靠回退标准 |
| 分析前 | LR 两个模型可能分别回退成不同拟合类型 | 不应直接解释混合模型与 OLS 的 llf 差值；保证同类可比较拟合或报告不可检验 |
| 与负责人讨论 | 将 bundle test 的 p≥.05 解读成“捆绑” | 未拒绝零假设不等于等效；报告证据不足，必要时预注册等效或精度标准 |
| 与负责人讨论 | 同身份翻译/原创对比也改变原始语言；France/Anglo 对比同时改变身份 | 是有意义的设计对比，但不能声称独立识别纯翻译效应 |
| 分析前 | bundle 输出未做 Holm 校正；各评分项内分别校正其他对比 | 确认检验族范围与报告要求，不能称全部结果都已多重校正 |
| 图与解释前 | 缺主图和人工理由抽检；translated/anglo 系数是简化关联模型 | 补区间和图，人工复核词表；勿把简化系数说成完全分离的因果效应 |
| 材料准备时 | 默认候选数 200 被整除取样为 3×66=198；各层不足时更少 | 属于“约 200”；看实际数量，不认为程序必然生成 200 |
| 材料准备时 | select 的 candidates_all 写在 prompt 去重前，但打印使用去重后数量 | 记录实际文件行数，并区分全通过片段池和唯一 prompt 池 |
| 材料准备时 | 记忆探测无重试、状态续跑，CSV 追加可能重复 | 加逐模型/段落状态与日志；探测未命中也不能证明不在训练集 |
| 结果检查时 | parse 会把合法小数四舍五入，regex fallback 只取一位数字 | 需先确定严格评分 schema；保留原文并标记无效响应，避免把非法数字解析成有效分数 |

原始模拟流程仅检验组合和解析路径，不验证真实服务、统计可靠性、文本筛选质量或研究假设。
