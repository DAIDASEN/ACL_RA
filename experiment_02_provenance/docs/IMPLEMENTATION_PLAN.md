## 不能自动化替代的步骤

人工候选审读、合理性判断、质量分档、模型/预算决定、预实验审阅及研究设计变更。不要在最终 CSV 中只留下“通过”而丢掉审核和修改记录。

## 结果解释

主要报告 1–7 分制分差、效应量、区间和 Holm 校正结果，不只列显著项。把模型间差异和总体结果分开。出处标签对评价的影响可以由此研究，但原始设计不能把所有语言、身份、渠道效应完全独立识别。
