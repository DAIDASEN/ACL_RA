## 原始规则与可复现性

老师脚本原件未修改。保持 min-score=2、seed=13、150–300 词、2022-11-30 之前、至多试六个打乱窗口、原文化/题材/实体/对话过滤以及每个 prompt 最多一篇的取样方法。默认 n=200 按整除分三档实际得到 198。

源数据 revision 为 6f0b721311a33736b19434e276f04727d5c2e213；全量加速运行 372.794 秒（不是本轮环境安装、开发与验证的总耗时）。软件、种子、代码哈希和日志见运行目录。

在前 1000 帖上，加速版和串行参考的两个 CSV 均逐字节一致；全量结果的前 20000 帖所保留 6043 段及全部来源元信息也与原串行流程一致（质量 tier 因全量分位数而另算）。原规则 198 段已逐段回查来源并用原始单段函数复核，全部通过。

全自动片段池有 12 条与前面记录完全重复的正文记录；原规则抽样及优先队列各自无重复正文/来源 prompt，未对原片段池静默去重。

## 为什么另做优先队列

对原抽样的分档抽读发现永生者、身体互换、时间回溯等明显或疑似科幻奇幻情节仍能漏过词表。可见“自动通过”不等于“适合实验”。原始 198 段和完整片段池均保留。

辅助队列额外参考原 prompt 和正文中的题材词、来源线索、英语表达，并用 POS 的 PROPN 标记减少遗漏人名。其完整正则、版本和随机种子记录在 priority_metadata.json。

82,184 段中，44,114 段命中 prompt 提示，5,240 段在此前未命中 prompt 的情况下命中正文提示；32,830 段未命中这些词表。随后按原质量档交错取样，仅对取样流中的 387 段做 POS 检查，189 段因 PROPN 被跳过，保留 198 段。**没有对全部 32,830 段都做 POS/人工验证。**

额外词表有意保守，会误排部分可用现实题材，且引用了原 prompt，因此只作为公开说明规则的阅读优先级；不能声称是老师原算法的同一抽样。定稿前应让老师了解并确认选材规则。它不修改正文，不填人工通过，不替代 2–3 位真人判断。

优先队列逐段来源回查和原规则复核也全部通过；技术检查 0 失败，归一化正文 0 重复。补充注意词表命中 1 段，未命中也不是合格证明。

助手对优先队列分档抽读 6 段，另列 3 段建议排除（R048 自主飞机叙述、R180 英语词语游戏、R188 作者附言）、2 段待核查、1 段可继续人工审读。详见 assistant_preview.csv。这些是非盲助手意见，未冒充真人判断，也未把剩余 192 段标为通过。
